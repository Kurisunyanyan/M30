# Macross 30: Voices across the Galaxy (PS3) - 中文汉化补丁分发仓库

本项目为 PS3 平台《超时空要塞 30：联系银河的歌声》（Macross 30 - Ginga o Tsunagu Utagoe，游戏编号 `BLJS10184`）的中文汉化补丁发布仓库。

本仓库仅包含经汉化处理后的成品补丁素材与图形化一键补丁器，不包含任何受版权保护的官方原版大文件或开发逆向工程脚本。

---

## 一、 补丁器运行模式

补丁器采用成对修补机制，严格保证光盘端（`/dev_bdvd`）与硬盘端（`/dev_hdd0`）大包哈希完全一致，杜绝冷启动时的校验报错：

| 模式名称 | 适用场景 | 输入要求 | 自动化流程 |
|---|---|---|---|
| **模式 1：ISO 镜像模式** | 玩家使用原版 `.iso` 镜像挂载运行 | 1. RPCS3 根目录<br>2. 原版 ISO 文件路径 | 原位修补 ISO 物理扇区 + 同步写平 `BLJS10184_INSTALL` + 部署汉化 `EBOOT.BIN` |
| **模式 2：解压光盘目录模式** | 玩家使用解压文件夹 (`PS3_GAME`) 运行 | 1. RPCS3 根目录<br>2. 光盘解压目录 | 修补光盘目录大包与 EBOOT + 同步写平 `BLJS10184_INSTALL` + 部署汉化 `EBOOT.BIN` |

## 三、 使用方式

运行图形化补丁器：
```powershell
python patcher_gui.py
```
选择对应模式并指定路径后，点击 **“开始执行汉化注入”** 即可全自动完成备份、注入与校验。
