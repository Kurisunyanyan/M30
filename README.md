# Macross 30: Voices across the Galaxy (PS3) - 中文汉化补丁分发仓库

本项目为 PS3 平台《超时空要塞 30：联系银河的歌声》（Macross 30 - Ginga o Tsunagu Utagoe，游戏编号 `BLJS10184`）的中文汉化补丁分发仓库。

本仓库包含经汉化处理后的成品补丁素材与图形化一键补丁器，不包含受版权保护的官方原版大文件。

---

## 一、 补丁器运行模式 (v1.5 通用版)

补丁器采用成对位级修补机制，严格保证光盘端（`/dev_bdvd`）与硬盘端（`/dev_hdd0`）大包哈希完全一致，杜绝冷启动时的校验报错：

| 模式名称 | 适用玩家 | 输入要求 | 自动化流程 |
|---|---|---|---|
| **模式 1：RPCS3 模拟器模式** | PC 电脑模拟器玩家 | 1. RPCS3 根目录<br>2. 原版 ISO 镜像 或 光盘文件夹 | 解包/修补 ISO 或文件夹 + 压制 64 部双语字幕 PAM + 同步更新 `BLJS10184_INSTALL` + 部署 1.02 汉化 `EBOOT.BIN` |
| **模式 2：PS3 实体机导出模式** | PS3 破解实机玩家 (CFW / HEN) | 1. 原版 ISO 镜像 或 光盘文件夹<br>2. **自定义输出目录** (免 RPCS3) | 独立导出汉化版 PS3 专用 ISO 或 JB 游戏文件夹 + 自动附带 1.02 汉化 EBOOT 与实机安装指南 |
| **模式 3：直接修补解压光盘目录** | 高级用户 / 定制打包 | 光盘解压目录 (`PS3_GAME`) | 就地原位修补选定目录中的大包、EBOOT 并压制 64 部 PAM 剧情动画硬字幕 |

> **提示**：补丁器内置【工作缓存目录】设置，默认自动选择剩余容量充足的磁盘分区，彻底避免 C 盘系统临时空间耗尽。

## 二、 PS3 实体机（已破解机）玩家使用指南

如果您手中有《超时空要塞 30》正版游戏光盘，且 PS3 已破解（CFW 或 PS3HEN）：

1. **提取光盘数据**：将正版光盘放入 PS3 光驱，打开 **multiMAN**（mM）或 **IrisMAN**，按 `△` 键选择“创建 ISO”或“复制”，将整张光盘 Dump 到内置硬盘或移动硬盘。
2. **生成汉化数据**：通过 FTP 或 U 盘将 Dump 出来的 ISO（或 `BLJS10184` 文件夹）传到电脑，启动本补丁器选择【模式 2：PS3 实体机导出模式】，指定输出文件夹后执行注入。
3. **部署至 PS3**：
   - 将生成的汉化版 ISO 拷贝至 PS3 内置硬盘 `/dev_hdd0/PS3ISO/`（或将游戏文件夹放至 `/dev_hdd0/GAMES/`）。
   - 在 PS3 上安装官方 1.01 与 1.02 升级补丁 PKG。
   - 用 multiMAN 文件管理器将输出目录中的 `PS3_HDD_UPDATE/dev_hdd0/game/BLJS10184/USRDIR/EBOOT.BIN` 覆盖到 PS3 的对应位置。
   - 使用 webMAN MOD 或 multiMAN 载入游戏即可畅玩全中文剧情、双语剧情动画与 1.02 全机体 DLC 内容。

## 四、 常见问题排查 (FAQ)

- **报错 `Cannot find .../PS3_GAME/PARAM.SFO`**：
  通常是由于系统 C 盘空间耗尽导致解包截断，或传入了非标准层级目录。请在补丁器中将【工作缓存目录】指定到剩余可用空间大于 35GB 的 D/E 盘。
- **报错 `No such file or directory: '.../130.pam.orig'`**：
  已在 v1.5 版本彻底修复。新版会在压制每个视频后立即自动清理中间文件，并增加了针对杀软扫描锁定的容错删除机制。
